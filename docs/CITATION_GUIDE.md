
Citation Guide for Vortex Framework

How to Cite Vortex

1. For Academic Publications (Recommended)

Use the Zenodo DOI for the most stable citation:

```bibtex
@software{vortex_framework_2026,
  author = {Baladi, Samir},
  title = {Vortex Multi-Parameter Assessment Protocol for Tropical Cyclone Rapid Intensification},
  year = {2026},
  publisher = {Zenodo},
  doi = {10.5281/zenodo.xxxxxxx},
  url = {https://doi.org/10.5281/zenodo.xxxxxxx},
  version = {1.0.0}
}
```

2. For PyPI Package Usage

If you installed from PyPI:

```bibtex
@software{vortex_pypi_2026,
  author = {Baladi, Samir},
  title = {vortex: Python package for tropical cyclone RI forecasting},
  year = {2026},
  publisher = {PyPI},
  url = {https://pypi.org/project/vortex/},
  version = {1.0.0}
}
```

3. For Git Repository Usage

Cite the specific repository version:

GitLab version:

```bibtex
@software{vortex_gitlab_2026,
  author = {Baladi, Samir},
  title = {Vortex Framework - GitLab Repository},
  year = {2026},
  publisher = {GitLab},
  url = {https://gitlab.com/gitdeeper3/vortex},
  version = {1.0.0},
  commit = "a1b2c3d4e5f678901234567890abcdef12345678"
}
```

Citation Elements

Required Elements:

· Author: Baladi, Samir
· Title: Vortex Multi-Parameter Assessment Protocol for Tropical Cyclone Rapid Intensification
· Year: 2026
· Version: 1.0.0
· URL/DOI: https://doi.org/10.5281/zenodo.xxxxxxx (or repository URL)

Optional Elements:

· Specific commit: For exact code version
· Software/package name: vortex (for PyPI)
· Platform: GitLab, Codeberg, Bitbucket

Version-Specific Citations

Version 1.0.0 (Current):

```bibtex
@software{vortex_v1_2026,
  author = {Baladi, Samir},
  title = {Vortex Framework Version 1.0.0},
  year = {2026},
  version = {1.0.0},
  doi = {10.5281/zenodo.xxxxxxx},
  url = {https://gitlab.com/gitdeeper3/vortex/-/tree/v1.0.0}
}
```
