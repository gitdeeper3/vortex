# 📊 تقارير نظام Vortex

## هيكل المجلدات:
- `daily/`      - تقارير يومية (تحذف بعد 7 أيام)
- `weekly/`     - تقارير أسبوعية (تحذف بعد 4 أسابيع)  
- `monthly/`    - تقارير شهرية (تحفظ لمدة سنة)
- `archived/`   - تقارير مؤرشفة

## تنسيق الملفات:
جميع الملفات بصيغة `.txt` مع الترميز UTF-8
تسمية الملفات: YYYY-MM-DD-HHMM-نوع-الحوض.txt

## مثال:
- 2024-02-10-1800-forecast-atlantic.txt
- 2024-02-10-1800-summary-atlantic.txt
- 2024-02-10-weekly-report-atlantic.txt
