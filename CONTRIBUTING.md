
Contributing to Vortex Forecast System

Development Setup

1. Clone the repository
2. Install dependencies: pip install numpy pyyaml
3. Install in development mode: pip install -e .
4. Run tests: python run_tests.py

Code Style

· Follow PEP 8 guidelines
· Use type hints for all function signatures
· Write docstrings for all public functions/classes
· Keep functions focused and modular

Testing

· Add tests for new features in tests/ directory
· Ensure all tests pass before submitting
· Use unittest framework for consistency

Report System

· All reports go in reports/ directory
· Use .txt format with UTF-8 encoding
· Follow existing naming conventions

Git Workflow

1. Create a feature branch
2. Make changes with descriptive commits
3. Run tests to ensure nothing breaks
4. Submit merge request
